# Changelog

All notable changes to this collection are documented here. Versions refer to skill-package frontmatter where applicable.

## Unreleased

### Added

- Added `drive-github-skill-audit`, a read-only workflow for comparing Drive skill definitions with a GitHub skills repository.
- Added generated catalog tooling, a deterministic collection validator, and GitHub Actions validation.
- Added contribution, conduct, support, and governance guidance, together with structured issue and pull-request templates.

### Changed

- Standardized skill names, concise routing descriptions, versioning, and H1 titles across the collection.
- Regenerated the skills catalog from current metadata.
- Reframed text revision and web-browsing guidance around transparency, authorization, and respect for access controls.
- Reworked the README, publishing checklist, and security policy for clearer installation, review, disclosure, and release workflows.
