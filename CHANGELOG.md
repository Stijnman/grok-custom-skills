# Changelog

All notable changes to this collection are documented here. Versions refer to skill-package frontmatter where applicable.

## Unreleased

### Added

- Added `drive-github-skill-audit`, a read-only workflow for comparing Drive skill definitions with a GitHub skills repository.
- Added generated catalog tooling, a deterministic collection validator, and GitHub Actions validation.
- Added contribution, conduct, support, and governance guidance, together with structured issue and pull-request templates.
- Added eight clearly named, reviewed skills: `product-opportunity-tree`, `research-interview-synthesis`, `product-requirements-document`, `architecture-decision-record`, `experiment-results-analysis`, `contact-vcard-export`, `accessible-color-review`, and `voice-agent-design`.
- Added Apache-2.0 attribution and third-party license material for the five product-management workflow adaptations.

### Changed

- Standardized skill names, concise routing descriptions, versioning, and H1 titles across the collection.
- Regenerated the skills catalog from current metadata.
- Reframed text revision and web-browsing guidance around transparency, authorization, and respect for access controls.
- Reworked the README, publishing checklist, and security policy for clearer installation, review, disclosure, and release workflows.
- Isolated high-impact unvetted candidate sources in a Google Drive review archive rather than publishing them without a dedicated safety and provenance review.
- Corrected malformed routing descriptions, clarified high-impact desktop and repository workflows, and resolved stale internal skill references.
- Renamed `controle-overview-skill` to `control-overview` and `skill-creation-enablerimage-processor` to `skill-asset-image-processor` for clear, capability-based routing.
- Replaced the dependency-broken optimization helper with a deterministic local validation and catalog-refresh workflow.
