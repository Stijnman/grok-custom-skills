## 🤝 How to Contribute

See [CONTRIBUTING.md](./CONTRIBUTING.md) for detailed contribution guidelines.

### Contribution Process

1. **Fork** the repository
2. **Clone** your fork locally
3. **Create** a feature branch (`git checkout -b feature/amazing-skill`)
4. **Make** your changes
5. **Add** tests and documentation
6. **Commit** with clear messages (`git commit -m 'feat: add amazing skill'`)
7. **Push** to your fork
8. **Open** a Pull Request to main branch
9. **Wait** for review and address feedback
10. **Celebrate** when merged! 🎉

### Skill Contribution Checklist

Before submitting a new skill:
- [ ] Read [PUBLISHING.md](./PUBLISHING.md) checklist
- [ ] Follow security requirements in [SECURITY.md](./SECURITY.md)
- [ ] Add proper metadata in SKILL.md frontmatter
- [ ] Include usage examples
- [ ] Add boundaries and limitations
- [ ] Document safety considerations
- [ ] Test thoroughly (see [TESTING.md](./TESTING.md))
- [ ] Run validation pipeline (`python3 scripts/optimize_all_skills.py`)
- [ ] Run tests (`python3 -m unittest discover -s tests -p "test_*.py"`)
- [ ] Update SKILLS_INDEX.md (or it will be auto-generated)

## 🎯 How to Add Yourself

1. **Edit** this file to add your contribution
2. **Follow** the existing format
3. **Add** your name, GitHub profile, and contributions
4. **Commit** with message: `docs: add [Your Name] to CONTRIBUTORS.md`
5. **Push** to your branch

**Format**:
```markdown
| Your Name | [@yourgithub](https://github.com/yourgithub) | Your contributions |
```

**Example**:
```markdown
| Jane Developer | [@janedev](https://github.com/janedev) | Added web-search skill, improved testing, fixed bugs |
```
