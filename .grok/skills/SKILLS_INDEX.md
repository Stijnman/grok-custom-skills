# Skill Library Pointer

The authoritative catalog for this repository is [SKILLS_INDEX.md](../../SKILLS_INDEX.md) at the repository root. It is generated from the current `SKILL.md` metadata by running:

```bash
python3 scripts/generate_catalog.py
```

Install individual packages from this directory or copy the collection into `~/.grok/skills/`. External backup and publication are separate, approval-gated actions; no skill change is synchronized automatically.
