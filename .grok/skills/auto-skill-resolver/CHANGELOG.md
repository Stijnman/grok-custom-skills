# Changelog — auto-skill-resolver

## [2.0.0] - 2026-08-12
### Added
- Full multi-destination persistence (Persistent Memory + Google Drive + GitHub)
- External skill download capability from GitHub and public sources
- Semantic version control system with CHANGELOG + versions/ history
- Mandatory registration of both new and original Grok skills into the unified persistence layer

### Changed
- Core workflow now treats persistence as non-negotiable
- Prefer external high-quality skills before creating from scratch

## [1.0.0] - 2026-08-12
- Initial creation (prompt analysis → local search → create via natural-language-to-skill)
