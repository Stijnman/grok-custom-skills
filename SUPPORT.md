# Support

Use the right channel so questions can be handled efficiently and sensitive information remains protected.

| Need | Recommended path |
|---|---|
| Using or installing a published skill | Review the [README](README.md) and [skills catalog](SKILLS_INDEX.md). |
| Proposing a new skill or improvement | Read [CONTRIBUTING.md](CONTRIBUTING.md), then open a structured GitHub issue. |
| Reporting a documentation or behavior problem | Open a bug report with a safe, minimal reproduction. |
| Reporting a security or privacy concern | Follow the private process in [SECURITY.md](SECURITY.md). Do not post sensitive details publicly. |
| Requesting broader product support | Contact the relevant agent-platform provider through its official support channel. |

Please include the skill name, repository commit, host environment, and a concise description of the expected and observed behavior when asking for help.
